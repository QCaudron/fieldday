# Satellite passes

We plan to make at least one QSO via amateur satellite during Field Day 2026, which earns a [bonus 100 points](./bonus_points).

## What to expect

A satellite station will be set up with the appropriate gear for working linear-transponder satellites. Successful satellite contacts also count toward the regular contact total (logged as a separate band).

## Pass predictions

Satellite pass predictions for the Field Day weekend (June 27–28, 2026) will be generated using the N2YO API approximately ten days before the event, when predictions become reliable. Check back here as Field Day approaches for the finalized pass schedule.

*Pass predictions will be finalized during the week before Field Day.*
